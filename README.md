# Subaru Outreach App

A single-page app. No install, no server. Everything is in index.html.

## Host it on GitHub Pages (about 3 minutes)
1. Go to github.com, tap New repository, name it subaru-outreach, and create it.
2. Upload index.html and .nojekyll (Add file, Upload files).
3. Open Settings, then Pages. Under Branch pick main and folder / (root), then Save.
4. In a minute your app is live at https://YOUR-USERNAME.github.io/subaru-outreach/
5. On your phone, open that link, then Share, Add to Home Screen. It now opens like an app.

## Things to know
- GitHub Pages is free for public repos only. Private repos need a paid GitHub plan. Anything inside index.html is visible to anyone if the repo is public, including the 5 starter prospects and their messages (the SEED list near the top of the script). Delete that list before uploading if you want them private.
- Your queue is saved in your own browser, not in the repo. Moving from the claude.ai link to GitHub starts empty. Use People, then Backup and restore, to copy your list over.
- Use the same phone and browser every time.
- To change the logo or wording later, edit index.html and upload it again.
- The "Write reply" button asks Claude directly when you open the app from the claude.ai link. On GitHub Pages it can't, so it copies a ready-made prompt instead: tap Open Claude, paste the prompt, then paste Claude's reply back into the box and continue as normal.
